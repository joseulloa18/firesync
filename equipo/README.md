Descarga el ZIP de tu nombre desde [Releases](https://github.com/joseulloa18/firesync/releases).
GitHub no ofrece descargar una subcarpeta directamente: los paquetes individuales
incluyen el lanzador y las instrucciones necesarias.

Una primera ejecución local y la autenticación son necesarias. Después, el kit
publica ramas y PRs automáticamente cuando las comprobaciones pasan. No integra
cambios a main sin revisión. Las credenciales permanecen en cada computadora.

Los cupos iniciales son dos por estación, pendientes de verificar en el ensayo.
Cada tarea está asignada y delimitada en un issue; no tomes tareas de otra persona.
